# Аватары, пьедестал и удаление дизлайков

Релиз добавляет загрузку, замену и удаление публичного фото аватара из Гаража для всех авторизованных участников. Фото подготавливается существующим выбором камеры/галереи, отправляется только после сохранения, проверяется по формату JPEG/PNG/WebP и ограничивается 4 МБ. В D1 хранится связь с владельцем, в R2 — изображение под случайным идентификатором. Заменённое изображение очищается, старый адрес перестаёт выдаваться. Аватар отображается в профиле, меню, форме публикации, карточках участника и предпросмотрах рамок. Премиальные рамки сохранены.

В разделе «Победители» — две доступные сообществу таблицы: Народный выбор (сердечки) и общий зачёт (сердечки + Моторы × 5). Колонки: место, никнейм/билд, конкурс, дата завершения, результат. Места 1–3 выдаются только работам с положительным результатом. При равенстве используется время заявки, затем порядок её записи, как в существующих правилах. Скрытые и отозванные заявки исключены; голоса вне интервала конкурса не учитываются. Время отображается по Europe/Lisbon. Таблица не создаёт новых наград за второе и третье места. Без завершённых результатов показывается пустое состояние, вымышленных победителей нет.

Кнопка дизлайка убрана из ленты, счётчик — из панели администратора. Серверные PUT/DELETE на старый адрес /dislikes/ больше не принимаются. Исторические отрицательные записи сохранены для совместимости, не влияют на победителей и не дают реферальной активности.

## Проверено

- Производственные API через SQLite/D1 и R2-адаптеры: авторизация аватара, чтение публичного фото, сохранение профиля, замена, удаление только владельцем, очистка старого изображения, отказ SVG/пустому файлу.
- Производственный расчёт трёх мест: никнеймы и дата, различные порядки двух зачётов, совпадение первого места с действующим победителем, скрытые заявки и поздние голоса.
- React-тесты реальных компонентов: загрузка/удаление аватара, отсутствие кнопки дизлайка, шесть призовых строк и даты в двух таблицах, обновление результатов.
- Общий набор npm test, TypeScript и производственная сборка.

Настоящая камера и выбор фото на физическом iPhone в этом прогоне не проверялись. Тесты не создают участников, конкурсы или награды в опубликованной базе.
