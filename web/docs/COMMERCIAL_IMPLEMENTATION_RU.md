# Tune Arena: коммерческая реализация (08.11.2026)
Автор: Vadym Tsinderhoz.

Текущая реализация заменяет коммерческие положения архитектуры v2.0. Обычная подача фиксируется; Премиум позволяет замену до дедлайна, а платная повторная подача после отказа возвращается на модерацию. Базовое участие бесплатно. Платные приоритет, рекламный закреп и слот дайджеста не меняют конкурсные баллы; один Мотор Премиума даёт 5 баллов только в общем зачёте.

## Реализованные модули
- `/partners`: предложения брендов и пакеты недели/месяца, рекламные материалы.
- `/business`: бренды, кампании, договорные референсы и обязательства по призу, отчёты/CSV; каталог, остатки, заказы, модерация, возвраты, трофеи.
- `/shop`: продукты/варианты, серверные цены, запрос счёта, Stripe Checkout, заказы/доставка/возврат, повторная подача по выданному праву.
- `/trophies`: награды владельца; `/trophies/{code}`: публичная проверка; API metadata для дополнительного ERC-721 выпуска.

Кампании публикуются после подтверждения материалов и приза. Маркировка рекламы обязательна. Отчёт содержит события видимости (50% блока, 1 секунда), переходы и открытия промокода с дедупликацией. Это не уникальные люди, не антифрод-верифицированные показы и не продажи партнёра. DNT отключает клиентскую отправку статистики. Спонсорское упоминание сохраняется в итогах.

Заказы резервируют остаток транзакционно на 24 часа. Отмена и истечение освобождают резерв однократно. Ключ повтора привязан к пользователю. Сервер определяет цену/валюту. Адрес доставки находится в отдельной закрытой таблице и доступен администратору при исполнении. Референс оплаты по счёту вводится после внешней сверки. Возврат Stripe выполняется через API; ожидающий возврат не помечается завершённым. Возврат физического товара в остаток производится вручную после фактического получения и сверки. Премиум продаётся на оплаченный срок без автоматического продления; пробные/реферальные периоды сохраняются.

## Внешняя активация
1. Указать продавца и реальные условия товара/возврата в `/business`, создать и опубликовать товары. В приложение не добавлены вымышленные цены, товары и действующие бренды.
2. Настроить `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`; endpoint `/api/payments/webhook`. Подписаться на checkout.session.completed, checkout.session.async_payment_succeeded, charge.refunded, charge.dispute.created. Цена, валюта, session и metadata сверяются с серверным заказом. Browser success URL не выдаёт права. Провести тестовую продажу и возврат в Stripe test mode перед подключением реального магазина.
3. Счета, печать/доставка мерча и призы исполняются продавцом/партнёром; приложение хранит статусы и внешние референсы. Автоматическое подключение print-on-demand поставщика и реальные банковские переводы не настроены.
4. NFT: выполнить `npm run contracts:build`; локально, на собственном устройстве, запустить `scripts/deploy-trophy-contract.mjs` с собственными RPC/кошельком. После развёртывания настроить `NFT_RPC_URL`, `NFT_CHAIN_ID`, `NFT_CONTRACT`. Приватные ключи в приложение не передаются. Победитель отдельно указывает адрес и согласие; организатор инициирует выпуск в своём кошельке. Сервер проверяет receipt, сеть, адрес контракта, Transfer от нулевого адреса, получателя, tokenId и подтверждения блоков. До этого minted-статус не устанавливается.

## Проверка
Производственные API тестируются с SQLite D1-адаптером, изолированными Stripe и RPC fixtures. Проверены роли, цены, остатки/гонки/истечение/отмена, приватность доставки, безопасные ссылки, подтверждение спонсора, метрики, возврат на модерацию, изоляция рекламного показа от рейтинга, подпись/сумма/повторы платежей, уникальность трофея, metadata и EVM-логи. Контракт компилируется с установленными OpenZeppelin Contracts и solc. Это не доказательство совершённой реальной продажи, доставки, договора или минта.

Первичные технические источники: https://docs.stripe.com/api/checkout/sessions/create ; https://docs.stripe.com/webhooks/signature ; https://docs.openzeppelin.com/contracts/5.x/erc721 . Зависимости и точные версии фиксирует package-lock.json; контракт использует MIT-лицензированную библиотеку OpenZeppelin.
