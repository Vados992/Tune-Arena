# Tune Arena — общий доступ и установка

Автор: Vadym Tsinderhoz. 7 ноября 2026.

Публичная ссылка для распространения: **https://tune-arena-vote.projectsentinel.chatgpt.site/install**. Любой посетитель может открыть страницу без приглашения, выбрать способ установки и открыть приложение. Для конкурсов и голосования требуется интернет; для публикаций и голосов — вход через ChatGPT. Это текущий настроенный провайдер, не анонимное голосование.

## Установка

| Устройство | Как установить |
|---|---|
| iPhone / iPad | Открыть ссылку в Safari → «Поделиться» → «На экран Домой» → «Добавить». Если показан переключатель веб-приложения, включить его. |
| Android | Chrome → кнопка «Установить» или соответствующий пункт меню браузера. Дополнительно на странице доступен тестовый APK для Android 8+. |
| Windows | Chrome / Edge → установка страницы как приложения из кнопки или меню браузера. |
| Mac | Chrome / Edge → установка страницы как приложения. Сам сайт также работает в современном Safari. |

Поддержка и названия пунктов зависят от браузера и версии ОС. При отсутствии browser-install диалога страница показывает ручные инструкции. Установленная PWA открывает тот же сервер и получает обновления интерфейса с него.

## Управление

Владелец входит своим подтверждённым аккаунтом и открывает `/admin`. Сервер сопоставляет аккаунт с секретом `TUNE_ADMIN_EMAIL`. Публичный доступ не выдаёт роль администратора. Администратор создаёт общий конкурс, задаёт время и условия, управляет работами и объявлениями. Тестовые 60-секундные раунды остаются отдельными от общего конкурса; галерейные примеры не дают реферальный прогресс.

Приложение не требует делать GitHub-репозиторий публичным: страницу, PWA и APK раздаёт HTTPS-сервер, исходники могут оставаться закрытыми. Деньги и выплаты не подключены; демонстрационная витрина приза не выполняет перевод.

## Отдельные файлы и магазины

Публичная PWA доступна сейчас. APK на странице — тестовый debug-пакет, не финальный магазинный релиз. Для постоянных Android-обновлений нужен собственный release-ключ и подписанный production APK/AAB. Для App Store и установки native iOS нужны Apple Team, подпись, тестирование и процедура распространения Apple. EXE/DMG также требуют отдельной успешной сборки и проверки. Код и workflows уже включены в репозиторий; их наличие не подменяет результат проверки установщиков.

Email/Telegram-вход можно активировать после настройки собственных провайдеров на сервере. Секреты вводятся в настройках хостинга, не в репозиторий и не в сообщения.

Официальные инструкции: [Apple: сайт как приложение](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/27/ios/27), [Chrome: веб-приложения](https://support.google.com/chrome/answer/9658361).
