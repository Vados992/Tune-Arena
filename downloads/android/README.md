# Проверенные Android-сборки 1.0.0

Собраны 7 ноября 2026 из исходников этого репозитория: `./gradlew --no-daemon assembleDebug bundleRelease lint`. Сборка и lint завершились успешно.

- `Tune-Arena-1.0.0-debug.apk` — устанавливаемая тестовая сборка; Android 8+. Подписана автоматически созданным **тестовым** Android debug-сертификатом, не ключом владельца приложения.
- `Tune-Arena-1.0.0-unsigned.aab` — неподписанный release bundle. Не устанавливается напрямую; для Google Play нужна собственная подпись.
- `SHA256SUMS` — контрольные суммы обоих файлов.

Устройство/эмулятор для проверки камеры и входа не использовались. По умолчанию открывается приватный пилот: нужен аккаунт с разрешённым доступом. Для собственного сервера изменить адрес в меню клиента.

Ключ тестовой подписи не опубликован. Следующая debug-сборка на другой машине может потребовать удаления прежнего APK перед установкой. Для обновляемых публичных версий используйте постоянный собственный release-keystore.
