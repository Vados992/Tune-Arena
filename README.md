# Tune Arena — macOS · iOS · Windows · Android

Автор: **Vadym Tsinderhoz**. Версия исходников: **1.1.0** (синхронизация с Sites v33, 11 ноября 2026). Все права на оригинальный код и бренд защищены.

Полный исходный проект текущей Tune Arena: социальная лента автотюнинга, загрузка и съёмка фото, **лайки и Турбо без дизлайков**, текущий и следующий туры, архив победителей, отдельная админка и организаторы, загрузка аватара и машины, Гараж, общие рамки аватара/поста, реферальная программа и удаление своего аккаунта с подтверждением. Репозиторий включает общую веб-/серверную систему и четыре платформенных клиента.

## Публичное приложение и установка

**[Открыть и установить Tune Arena](https://tune-arena-vote.projectsentinel.chatgpt.site/install)** — PWA для современных iPhone/iPad, Android, Windows и Mac. Просмотр доступен без приглашения, для публикаций и голосов нужен аккаунт. Пользовательская регистрация — только через Telegram; для собственного сервера требуется настройка Telegram OIDC. На той же странице доступен Android **тестовый** APK. Возможность установки зависит от браузера и версии ОС; конкурсы требуют интернет.

[Как распространять приложение](docs/PUBLIC_RELEASE_RU.md). Отдельные нативные установщики и публикация в магазинах имеют собственные проверки и подпись, описанные ниже.

## Что находится в репозитории

| Платформа | Исходники | Сборка | Результат |
|---|---|---|---|
| macOS 13+ / Intel и Apple Silicon | `desktop/` + `macos/` | Electron + electron-builder на Mac | `.dmg` и `.zip` |
| Windows 10/11 x64 | `desktop/` + `windows/` | Electron + electron-builder на Windows | установщик NSIS `.exe` и portable `.exe` |
| iOS 16+ / iPhone и iPad | `ios/` | полноценный проект Xcode, SwiftUI + WKWebView | приложение симулятора; архив устройства; подписанный IPA после настройки Apple Team |
| Android 8+ | `android/` | Android Studio / Gradle, Java + WebView | debug `.apk`; release `.aab`, подпись отдельно |
| Общий интерфейс и сервер | `web/` | React/Vinext + Cloudflare Worker | веб-приложение, API, D1, R2 |

Клиенты — устанавливаемые **подключённые приложения**. Они используют один HTTPS-сервер и одну базу, поэтому участники всех платформ видят одинаковые конкурсы и реакции. Интерфейс и бизнес-логика находятся в `web/`, а не скопированы в четыре расходящиеся реализации. Интернет необходим. Это не четыре независимых офлайн-базы.

Исходники проектов и процессы сборки не равнозначны четырём уже подписанным и проверенным установщикам. Фактически выполненные проверки перечислены в [docs/VERIFICATION.md](docs/VERIFICATION.md). Автоматические сборки создают артефакты только после успешного завершения GitHub Actions.

## Быстрый запуск на компьютере

Нужен Node.js 24. Для запуска тестов также нужен Python 3.

```sh
git clone https://github.com/Vados992/Tune-Arena.git
cd Tune-Arena
npm run setup
npm run dev
```

Открыть **http://localhost:5173**. На начальной странице нажать **DEMO · Local driver**, выбрать никнейм. В локальном деморежиме этот тестовый аккаунт может открыть `/admin` и создать конкурс. При необходимости создать отдельный приватный тестовый тур в админке; публичная лента показывает работы участников.

`npm run setup` устанавливает веб-зависимости, создаёт игнорируемый `.dev.vars`, собирает сервер и применяет миграции к локальной базе. Повторный запуск сохраняет ранее применённые миграции. Локальные данные не являются данными опубликованного сайта.

Демовход разрешён только при явных настройках development + localhost. В production он отключён и покрыт отрицательными тестами. В публичной версии администратор определяется сервером по подтверждённой идентичности, а не никнейму.

## Запуск macOS / Windows клиента

```sh
npm run desktop:install
npm run desktop
```

По умолчанию клиент открывает `https://tune-arena-vote.projectsentinel.chatgpt.site`. 7 ноября включён общий доступ к просмотру и странице установки. Публикации и голоса требуют входа; администратор проверяется сервером по подтверждённому аккаунту владельца. Изменить сервер можно в меню клиента, либо сразу для всех проектов:

```sh
npm run configure -- https://your-app.example
```

Платформенные клиенты сохранены без изменений. Меню клиента по-прежнему позволяет сменить HTTPS-сервер; старое поле email-ссылки больше не является способом регистрации текущего web-приложения. Переход Telegram OIDC во встроенном браузере требует отдельной проверки на устройствах.

[Скачать APK](downloads/android/Tune-Arena-1.0.0-debug.apk) · [Проверка и SHA-256](downloads/android/README.md). APK и unsigned AAB действительно собраны; установка и камера на физическом устройстве ещё не проверены.

## Четыре сборки

- **macOS:** на Mac выполнить `npm run desktop:install`, затем `npm run macos`. Файлы появятся в `desktop/dist/macos/`. [Инструкция](macos/README.md).
- **Windows:** на Windows выполнить `npm run desktop:install`, затем `npm run windows`. Файлы появятся в `desktop/dist/windows/`. [Инструкция](windows/README.md).
- **iOS:** открыть `ios/TuneArena.xcodeproj`, выбрать схему `TuneArena` и симулятор. Для физического iPhone выбрать собственный Apple Team. [Инструкция](ios/README.md).
- **Android:** открыть папку `android/` в Android Studio или запустить `./gradlew assembleDebug` с JDK 17+ и Android SDK 36. [Инструкция](android/README.md).

GitHub Actions: [проверки](.github/workflows/verify.yml) и [четыре платформенные сборки](.github/workflows/build-clients.yml). Вторая workflow создаёт тестовые macOS/Windows-пакеты без сертификатов, Android debug APK и unsigned AAB, iOS simulator app и unsigned device archive. Она не публикует приложение в магазины и не создаёт подписанный IPA без Apple Developer credentials.

Первый облачный запуск 7 ноября остановился до выполнения шагов всех заданий; macOS/Windows/iOS-сборки пока не подтверждены. [Фактические результаты](docs/VERIFICATION.md). Android APK собран отдельно и доступен выше.

Для владельца самостоятельного сервера задаётся `TUNE_ADMIN_TELEGRAM_ID` — числовой ID подтверждённого Telegram-аккаунта. Email, Google, Apple и телефонная регистрация отключены. Ключи, сертификаты, данные пользователей и секреты опубликованного пилота в репозиторий не включены. В коде есть серверные модули заказов/Premium, спонсорства и трофеев. Наличие этих модулей не означает подключённых платежей, выполненных переводов или выпуска NFT: требуются отдельные настройки и эксплуатационная проверка.
